# Роли UZGERMED 2.8.0

| Роль | Возможности | Ограничения |
|---|---|---|
| Сотрудник / оператор | Счета и начальные остатки, фактические операции, собственные заявки, импорт операций и планов, ручные планы А/Б/В, прогноз | Не согласует платежи, не задаёт лимиты, не управляет пользователями |
| Финансист / казначей | Финансовый ввод, проверка и редактирование заявок, первая ступень согласования, бюджеты и планы | Не подтверждает за директора, не меняет пороги директора и пользователей |
| Директор | Финансовое редактирование, аналитика, бюджеты, планы, пороги UZS/USD/EUR, вторая ступень согласования, журнал | Не управляет учётными записями; не может обойти проверку финансиста, подтвердить собственную или последнюю отредактированную им заявку |
| Инвестор / управленец | Обзор, Cash Flow, планы А/Б/В, счета, операции, прогноз, экспорт | Только просмотр финансов; нет записи данных, согласования, импорта или управления пользователями |
| Администратор | Пользователи, роли, блокировка, сброс пароля, все финансовые функции | Самосогласование и подтверждение обеих ступеней одним сотрудником запрещены |

Существующие роли кассира, бухгалтера, инициатора и аудитора сохранены. Действующие пользователи автоматически не переназначаются.

## Порядок согласования

Оператор/кассир создаёт заявку → отдельный финансист проверяет → при сумме выше порога валюты отдельный директор подтверждает → фиксируется фактическая оплата. До порога включительно достаточно финансиста. Без заданного порога директор нужен для всех сумм. При редактировании или переносе срока согласование сбрасывается. Денег на выбранном счёте должно хватать с учётом других резервов.

Начальный остаток вводится для каждого банка и кассы отдельно на выбранную дату, например 01.09.2026. Он не считается доходом. Валюты и компании не смешиваются.

Выбор А/Б/В — ручной. Пока не согласованы точные правила автоматического переключения, программа не выбирает сценарий вместо пользователя.

Сессия длится 60 минут. Администратор не видит сохранённые пароли: доступен сброс, который завершает прежние сессии. Инвестор может менять собственный пароль в профиле; это не даёт прав финансовой записи.

Количество пользователей не ограничено программно. Ограничений доступа по отдельным компаниям/счетам пока нет: финансовые роли видят доступные в системе компании. Перед добавлением внешнего инвестора нужно определить, допустим ли ему такой общий просмотр.

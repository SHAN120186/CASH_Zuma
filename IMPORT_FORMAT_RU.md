# Импорт операций из Excel/CSV

Система не считает произвольный бухгалтерский файл совместимым автоматически. Перед рабочим импортом нужно подтвердить лист и колонки исходного файла.

Поддерживаемые колонки первого листа:

`Дата; Тип; Счёт; Счёт назначения; Статья; Сумма; Контрагент; Документ; Комментарий`

- Тип: `Поступление`, `Выплата` или `Перевод`.
- Счёт и статья: точное название из справочника либо их ID.
- Документ: уникальный номер в пределах счёта.
- Дата: `ГГГГ-ММ-ДД`; сумма — положительное число.
- Для перевода нужен счёт назначения; для поступления/выплаты — статья.

Сначала выполняется предпросмотр без записи. Ошибки показываются по строкам. Подтверждение доступно только после успешной проверки всех строк. Один пакет нельзя подтвердить дважды; повторная загрузка уже подтверждённого идентичного файла блокируется. Исправленный файл имеет другое содержимое и проходит обычную проверку заново.

Компания определяется выбранным счётом. Поэтому до импорта каждый банковский счёт и касса должны быть отнесены к подтверждённой компании.
